MCU sort

A python program that sorts through and organizes a list of Marvel Movies according to user input.

- All movie data is stored in a json file
- The program reads in the json file and creates a list of movie objects from it
- through the command line, the user is able to choose from a series of options to request data
- Bubble sort is used to restructure the movie list according to release order or chronological order, accounting for months as well as years
- The user is able to request specific keywords and characters, activating search algorithms which print all the movies featuring those keywords
- partial matches and caps are also accounted for
